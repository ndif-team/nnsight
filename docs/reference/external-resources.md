# External Resources

| Resource | URL | When to go there |
|----------|-----|------------------|
| Documentation site | [nnsight.net](https://nnsight.net) | User-facing docs and the interpretability tutorials (walkthrough, logit lens, patching, SAEs, …). |
| GitHub | [ndif-team/nnsight](https://github.com/ndif-team/nnsight) | Source, issues, releases. |
| Discord | [discord.gg/6uFJmCSwW7](https://discord.gg/6uFJmCSwW7) | Quick questions to the team and users. |
| Forum | [discuss.ndif.us](https://discuss.ndif.us) | Long-form questions, NDIF support. |
| Paper | [arXiv:2407.14561](https://arxiv.org/abs/2407.14561) | Cite this if you use nnsight in research. |
| NDIF login | [login.ndif.us](https://login.ndif.us) | Get an NDIF API key ([remote/api-key-and-config.md](../remote/api-key-and-config.md)). |
| NDIF status | [nnsight.net/status](https://nnsight.net/status) | Which models are deployed (or call `nnsight.status()`). |
| NDIF skills | [ndif-team/skills](https://github.com/ndif-team/skills) | Claude Code / Codex plugin with nnsight skills. |
| nnterp | [ndif-team/nnterp](https://github.com/ndif-team/nnterp) | Standardized transformer interfaces across model families, built on nnsight. |
| nnsight-vllm-demos | [ndif-team/nnsight-vllm-demos](https://github.com/ndif-team/nnsight-vllm-demos) | Demo apps, including async chat with SAE-based steering. |
